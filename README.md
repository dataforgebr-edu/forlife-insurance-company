## Forlife insurance company
Essa é uma empresa do ramo de suguros que vende apólices de 3 segmentos diferentes vida, automóvel e residência. 
Com o seu crescimento surgiram diversos problemas relacionados a dados como difentes números para o mesmo indicador, silos entre as áreas e demora na obtenção das informações para tomada de decisão.

# Missão
Cria um ambiente de dados que possibilite a análise compartilhamento e acesso rápido as informações de diferentes sistemas da companhia e mantendo a governaça sobre estes ativos de dados.

* Etapa 1 - Criar a estrutura de dados da companhia usando faker.
